# **App Name**: Hostel In

## Core Features:

- Role-Based Secure Authentication: Differentiated login flows for Warden, Student, Hostel Monitor, and Staff, with an initial registration requirement that students must be pre-allotted by a Warden to gain system access.
- Personalized Dashboards: Dynamic dashboards customized to each user's role, displaying relevant information, actionable items, and notifications tailored to their responsibilities.
- Comprehensive Admin & Operational Control: A consolidated panel for Warden, Monitor, and Staff. Warden can manage hostel descriptions, room allotments, staff roles, oversee financial transactions (mess fees, expenses), track cleanliness schedules, and resolve student complaints. Monitor and Staff have restricted access for their specific duties like mess menu updates and fee marking.
- Student Interaction & Information Hub: A portal for students to view their allocated rooms, facilities available, vacant room status, submit new complaints, and request permissions.
- Geofenced Daily Student Presence: An automated system enabling students to mark their daily presence within a specific time window (8 PM - 11 PM IST) and while located within a 100m radius of the hostel.
- AI-Enhanced Communication Tool: A generative AI tool for Wardens and Monitors to assist in drafting official announcements, policy updates, or summarizing common complaint themes to facilitate resolution and communication.
- Dedicated Student-Monitor Chat: A real-time, common chat section exclusively for students and the Hostel Monitor to facilitate direct and efficient communication within the hostel community.

## Style Guidelines:

- Primary color: Muted, professional blue (#336699) to convey trust, stability, and reliability appropriate for a management application.
- Background color: A very light, desaturated blue-gray (#EEF3F7) for a clean, unobtrusive canvas that ensures content readability in a light theme.
- Accent color: A vibrant aqua (#44D6D6) analogous to the primary hue, providing a clear and refreshing highlight for interactive elements and calls to action.
- Body and headline font: 'Inter', a modern grotesque sans-serif chosen for its objective readability and versatility across various textual content, suitable for both headlines and detailed information displays.
- Utilize a consistent set of clean, line-style icons to clearly represent actions, user roles, statuses, and navigation within the management system.
- Employ a fully responsive design, adapting fluidly across desktops, tablets, and mobile devices, ensuring optimal user experience on any screen size. Dashboards should be structured hierarchically for intuitive navigation.
- Implement subtle and purposeful animations for user feedback, such as state changes upon action completion (e.g., complaint marked solved, attendance marked), and smooth transitions between dashboard sections or role switches.
